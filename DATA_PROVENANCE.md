# Synthetic data provenance

`data/` contains the organiser-provided synthetic challenge samples from
https://github.com/joaoalves3901/JunctionX-QuantumTrace
(source snapshot: `39e8f18dcfb5edc66eda0f47bb44884aa7db5c9c`).
These sample bytes were preserved unchanged in the v0.3.3 release.

`samples/` and `Preparacao/FICHEIROS_NOVOS/` contain developer-created
synthetic examples; see their accompanying documentation for expectations.

The root MIT license covers the QuantumTrace implementation. Third-party
data and external dependencies retain their respective provenance and
licensing; the root license does not assert ownership of organiser data.
No user upload history or private runtime database is included.
